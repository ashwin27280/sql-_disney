# Disney+ SQL Data Analysis Project

## Overview  
- This project involves a comprehensive analysis of the Disney+ Titles dataset using SQL.  
- The dataset contains information about movies and TV shows including title, director, cast, country, release year, rating, duration, genre, and description.  
- The main goal is to extract meaningful business insights from the dataset.  
- The analysis focuses on content distribution, trends, and patterns on the Disney+ platform.  

## Objectives  
- Analyze the distribution of content types (Movies vs TV Shows).  
- Identify the most common ratings for movies and TV shows.  
- Analyze content trends based on release year and date added.  
- Identify top countries producing Disney+ content.  
- Explore duration patterns for movies and TV shows.  
- Categorize content using keywords from descriptions.  
- Identify frequently appearing actors and directors.  
- Apply SQL techniques such as aggregation, string functions, and window functions to derive insights.
